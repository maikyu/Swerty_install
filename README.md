Swerty keyboard install


Simple script which installs the swerty keyboard layout for ansi keyboards. Read more about swerty here: https://johanegustafsson.net/projects/swerty/

To install it simply run curl https://raw.githubusercontent.com/maikyu/Swerty_install/refs/heads/head/swertyinstall.sh | sudo bash 
Afterwards go into settings and change the keyboard layout there, it will be under Swedish as a variant named Swerty. 

Made this for myself as the layout gets removed after updating system for easier install. Works on CachyOS and will likely also work on Arch and other Arch based installs.
